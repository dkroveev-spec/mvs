# mvs

Тихий мессенджер с характером.

</div>

---

## Что это

mvs — клиент Telegram с собственной системой оформления **Ink**: тёплая бумага,
графит, терракота, серифные заголовки и тонкие линии вместо теней. Внутри —
плагины с разрешениями, локальные настройки и экран «Защита», который
показывает факты, а не проценты.

## Ink

- бумага `#F5F1E8`, графит `#151412`, терракота `#D9552F`;
- **Lora** — заголовки, имена и словесный знак `mvs.`;
- **Inter** — интерфейс и текст сообщений;
- один акцент, хайрлайны, спокойные анимации;
- знак: графитовый квадрат, кремовый сериф `mvs` и терракотовая искра.

## Возможности

- оформление Ink для светлой и тёмной темы, плашка mvs в настройках;
- Java- и Python-плагины с моделью разрешений и журналом действий;
- тихая печать — клиент не отправляет «печатает…»;
- локальный профиль, стример-режим, экран приватности;
- экспорт чата в Markdown, шаблоны и быстрые ответы;
- экран «Защита»: подпись APK, состояние проверок, плагины.

## Сборка

Каждый пуш в `main` собирает APK в GitHub Actions и публикует его в
[Releases](../../releases). CI подписывает сборку отладочным ключом, поэтому
установка поверх другой сборки требует удаления приложения.

## Лицензия

GPLv3. Проект использует открытый код Telegram Android и клиентов на его
основе; лицензии шрифтов лежат в `TMessagesProj/src/main/assets/fonts`.
